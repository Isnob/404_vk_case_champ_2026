## Технические ограничения и развилки

- Справка VK рекомендует XLSX для каталога, который ведут вручную, CSV для выгрузки из CMS или 1С, YML для готового товарного фида. Для XLSX/CSV требуется сохранить структуру шаблона и порядок колонок. Для YML обязательны `id`, `name`, `description`, `picture`, `price`; изображения должны быть доступны по ссылкам. [Скриншот справки](screenshots/06-import-help.png).
- Интеграция Ozon запускается в Ozon Seller: продавец связывает кабинет с существующим или новым бизнес-сообществом. По материалам Ozon, цены, остатки и содержимое карточек синхронизируются автоматически, а заказы отображаются в Ozon Seller. [Инструкция Ozon](https://integration.ozon.ru/), [пример пути покупателя](https://seller.ozon.ru/media/boost/kak-rabotaet-integraciya-ozon-i-vkontakte/).
- Это разные пути продаж: товар собственного каталога VK и товар, связанный с Ozon, нельзя автоматически объединять в одну метрику заказов внутри VK.

## Открытые вопросы для Q&A

1. При каких настройках покупатель видит стоимость и срок доставки СДЭК до оформления заказа? Почему в проверенном сценарии доставка осталась «оплачивается отдельно» после выбора ПВЗ и заполнения габаритов?
2. Какие требования и шаги нужны бизнесу для подключения онлайн-оплаты через VK Pay? Какова доля начавших и завершивших подключение?
3. Как учитываются в целевой метрике заказы по товарам Ozon, если оформление передаётся партнёру, а заказ появляется в Ozon Seller?
4. Обновляются ли товары, цены и остатки автоматически после импорта по ссылке на YML/CSV, и с какой частотой?
